Fairness notes

  • DB access, validation and the CPU workload live in one shared package. Each framework only wires routes, parses bodies and renders JSON.
  • No request logging on any framework. Every container gets a 65535 open-file limit.
  • The posts table is reset to the same 100 seeded rows before each framework runs.
  • k6, Postgres and the server share the same 4 vCPUs, so absolute numbers are lower than on a dedicated setup. The comparison is still like for like.
